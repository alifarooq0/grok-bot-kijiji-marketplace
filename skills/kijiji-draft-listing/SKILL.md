# Draft a Kijiji listing

## Goal

Produce a clear, honest ad that sells without sounding spammy.

## Collect first

- Item name, brand/model, age, condition
- Asking price (or ask to research with kijiji-price-research)
- What’s included, defects, reason for selling
- Meetup area and preferred payment (cash / e-transfer — never pressure)

## Write

1. **Title**: specific and searchable (brand + model + key trait). Avoid ALL CAPS and “OMG DEAL”.
2. **Price**: round, market-aware; note if firm or open to offers.
3. **Description** (short paragraphs):
   - What it is and condition
   - Specs / size / extras
   - Honest flaws
   - Pickup / delivery / meetup area
4. Suggest photo order: hero shot, details, flaws, accessories.

## Output

- Ready-to-paste title
- Ready-to-paste description
- Suggested price + 1-line rationale
- Photo checklist
